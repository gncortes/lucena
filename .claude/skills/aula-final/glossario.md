# Glossário do Lucena (pt)

O texto das aulas segue esta lista mesmo quando a fonte usa outra palavra. O revisor reprova a fala que foge dela.

| Use | Não use | Observação |
|---|---|---|
| capturar, captura | comer, pegar, tomar | "o rei captura o peão" |
| alcançar (o peão, a casa) | pegar, chegar a tempo de pegar | corrida do rei |
| simplificar (para a Lucena) | trocar para chegar | trocar peças para cair numa posição conhecida |
| promover, coroar | virar dama | "o peão coroa" ou "promove a dama" |
| oposição, triangulação, casas-chave, zugzwang | nomes inventados | nomes consagrados |
| corte (do rei), cortar | barrar, prender (quando é corte de torre) | |
| xeques laterais, defesa frontal, lado curto, lado longo | | finais de torre |
| ponte (Lucena) | escudo | "construir a ponte" |
| peão passado, peão passado afastado, peão protegido | | |
| afogamento, afogar | travar o rei | |
