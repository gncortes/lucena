Visão: seções 2, 17, 19, 25 e 29. Junta as fases 1 (fundação) e 3 (finais) do roadmap.

- [x] Escada de níveis em dados (`assets/progression/ladder.json`): 1000 → 1200 → … → 2600 → Stockfish, cada degrau com seus desafios (posição + adversário + objetivo); o Stockfish é a etapa final separada
- [ ] Conteúdo do degrau 1000 → 1200 (iniciante): dama, torre, peões, oposição, regra do quadrado, promoção, peças menores simples, partindo da lista `BEGINNER` de `tools/import_positions.py`; lista fechada com o Gabriel antes de codar. Os outros degraus ficam com o esqueleto e conteúdo mínimo — proposta em `assets/progression/ladder.json` (só posições do catálogo), aguardando o ok do Gabriel
- [x] Domínio: desafio concluído quando o objetivo é cumprido contra o adversário do desafio; degrau seguinte desbloqueia ao concluir o atual
- [x] Histórico de partidas completo no drift (lances, adversário e nível, ritmo, duração, resultado), migração das tentativas atuais sem perda
- [x] Tela "Jornada" na tela inicial: onde estou, próximo nível, degraus bloqueados/liberados, desafios com marca de concluído; histórico por desafio agrupado por mês

**Cenários Patrol:**

1. (adversário falso) Concluir todos os desafios do degrau 1000 → degrau 1200 liberado → reiniciar → continua liberado
2. Perder um desafio → nada concluído, tentativa no histórico
3. Degrau bloqueado → tocar mostra o que falta
4. Histórico de um desafio mostra as partidas por mês, mais recente primeiro
5. Atualizar de uma versão com tentativas antigas → marcas do catálogo continuam
